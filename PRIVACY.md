# Confidentialité — Pack Emploi Maroc

- Le CV Builder et le suivi des candidatures utilisent le stockage local du navigateur.
- Les données saisies dans ces pages statiques ne sont pas envoyées à un serveur par le code actuel.
- L'analyse ATS intégrée fonctionne localement dans le navigateur.
- Ne placez jamais de mot de passe, clé API, token ou document d'identité dans le dépôt GitHub.
- Avant publication d'une version avec paiement ou IA côté serveur, les secrets devront être stockés uniquement dans les variables d'environnement de l'hébergeur.
- Le produit final devra afficher clairement les conditions de vente, la politique de confidentialité et les modalités de remboursement avant paiement.

Ce document décrit le comportement de la version statique actuelle et devra être mis à jour si un backend est ajouté.
